# Vinkup frontend

The React app of Vinkup (React 19, TypeScript, Vite). Setup, scripts and the project overview are in
the [root README](../README.md); how the frontend is organised is in the
[architecture overview](../docs/architecture-overview.md#4-frontend), and coding rules are in the
[conventions](../docs/conventions.md#10-frontend).

Run it from the repository root:

```bash
npm run dev:frontend
```

Set `VITE_USE_MOCKS=true` in `frontend/.env.local` to run it on sample data without the backend.
